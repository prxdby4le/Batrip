## 🔍 METODOLOGIA

### Como foi analisado:
1. ✅ Leitura do código CSS
2. ✅ Identificação de todas as combinações cor/fundo
3. ✅ Cálculo matemático de contraste (fórmula WCAG)
4. ✅ Comparação com padrões AA/AAA
5. ✅ Verificação de contexto (tamanho, peso, uso)

### Fórmula utilizada:
```
Contraste = (L1 + 0.05) / (L2 + 0.05)

Onde:
L1 = Luminância da cor mais clara
L2 = Luminância da cor mais escura

Resultado:
>7:1 = AAA (Excelente)
>4.5:1 = AA (Adequado)
<4.5:1 = Falha
```
